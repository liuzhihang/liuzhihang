- AI brand icons: [Lobe Icons](https://github.com/lobehub/lobe-icons), sourced from [`@lobehub/icons-static-svg@1.106.0`](https://unpkg.com/@lobehub/icons-static-svg@1.106.0/package.json). The Toolkit mark is recolored.
- Doc View demo still: from the historical API documentation generation demo linked in the [Doc View README](https://github.com/liuzhihang/doc-view/blob/38bc93b95be355d6434b71f1160edfb149c87ee9/README.md).
